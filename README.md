### Pourquoi B n'a pas de ticket

Une table en base est un moyen, pas un besoin : elle ne dit ni pour qui ni pourquoi. Le besoin réel derrière cette demande sera porté par les stories qui en ont besoin (par exemple l'affichage des commandes en cuisine, EX-F-17, si Nadia le confirme) et la table sera créée comme tâche technique de ces stories.
